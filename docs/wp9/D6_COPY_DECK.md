# D6 Plain-Language Copy

| System term/state | User-facing wording |
|---|---|
| ASK | Needs your decision |
| SUGGEST | Suggested for you |
| SHADOW | Watching only |
| Level 0 | Watching |
| Level 1 | Suggests |
| Level 2 | Acts with undo |
| Level 3 | Acts automatically |
| needs_reconciliation | Result not confirmed |
| unavailable | This information is unavailable right now. |
| unsupported operation | Probation cannot do this safely yet. |
| queued/HTTP 202 | Request received. Probation is still processing it. |
| unknown side-effect result | Probation could not confirm whether this happened. Check the email before trying again. |

Use action labels that name the effect: “Archive email”, “Move to trash”, “Send this reply”, “Forward email”, “Reject suggestion”, “Leave as is”.

Use “Why” or “Details” for source citations, evidence cutoffs, model explanation, and technical terms. Never hide a restriction, uncertainty, cost, or unsupported capability to make copy shorter.
