# Historical results: unverified and superseded as release evidence

Added 22 October 2026 during WP0. Existing JSON, tables and phase reports are preserved
as historical artifacts; their numerical content has not been replaced by new guesses.

The audit in `docs/reports/changes-audit-2026-10-22.md` found hard-coded ablation values,
incomplete data identity/chronology, empty-sample rates and incomplete baseline/model
execution. Consequently the existing results and claims derived from them must not be
used as validated performance evidence for the completed product. Old phase reports
record historical claims, not acceptance of the repaired pipeline.

Replacement release evidence requires WP2 input/chronology repairs, the relevant model,
exam and execution work, and actual WP10 experiments with manifests, seeds, model/prompt
versions, data hashes, denominators, cost and negative results. None is claimed here.
New CLI runs default to `data/results/`; publication is explicit and reviewed.
