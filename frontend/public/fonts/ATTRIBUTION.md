# Font attribution

The dashboard self-hosts two variable font files from Google Fonts:

- **Fraunces** — designed by Phaedra Charles and Undercase Type. SIL Open Font License 1.1.
- **Manrope** — designed by Mikhail Sharanda. SIL Open Font License 1.1.

License: https://openfontlicense.org/open-font-license-official-text/

The files are bundled with the frontend and served from `/fonts/`; the app makes no remote font request. Only the Latin subset is included.
